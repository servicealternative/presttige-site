# AI Test Profiles

This folder holds synthetic AI-generated test profile photos for Presttige Circle discovery testing.

These profiles are never real members. They must never appear in any real metric, dashboard, count, statistic, or analytic. They are synthetic test material only, removable in bulk, and used only while discovery is in test mode.

Discovery remains controlled by the master switch and must stay off until Antonio explicitly enables it.

## Folder Pattern

Each profile uses one folder:

```text
AI-01/
AI-02/
AI-03/
AI-04/
```

To add more profiles, create the next numbered folder, for example:

```text
AI-05/
AI-06/
AI-07/
```

Use two digits for consistency.

## Photo Naming

Each `AI-NN` folder holds exactly six photos:

```text
1.jpg
2.jpg
3.jpg
4.jpg
5.jpg
6.jpg
```

`1.jpg` is the face and main profile photo. Photos `2.jpg` to `6.jpg` are supporting profile photos.

Do not place real member photos here.
